# kiff-fixtures

Releases for testing the [Kiff](https://github.com/linroid/Kiff) GitHub Action, which generates
patches between the files of a project's releases. The action's tests read these releases; they
never write to them. **Do not edit or delete the releases.**

Every file is generated by [`make-fixtures.py`](make-fixtures.py) from a seeded generator, so
`python3 make-fixtures.py dist` writes identical bytes. Each version is its parent plus a small
mutation, like consecutive builds of a real app.

## Releases

In the order they were published:

| Release | Parent | Kind | Assets |
| --- | --- | --- | --- |
| `v1.0.0` | | release | `app-1.0.0.apk`, `desktop-1.0.0.zip`, `tool-1.0.0.bin`, `noise-1.0.0.bin` |
| `v1.1.0` | `v1.0.0` | release | `app-1.1.0.apk`, `desktop-1.1.0.zip`, `noise-1.1.0.bin` (no `tool`) |
| `v1.2.0` | `v1.1.0` | release | `app-1.2.0.apk`, `desktop-1.2.0.zip`, `tool-1.2.0.bin`, `noise-1.2.0.bin` |
| `v1.3.0` | `v1.2.0` | release | `app-1.3.0.apk`, `desktop-1.3.0.zip`, `tool-1.3.0.bin`, `noise-1.3.0.bin` |
| `v1.2.1` | `v1.2.0` | release, published after `v1.3.0` | `app-1.2.1.apk`, `desktop-1.2.1.zip`, `tool-1.2.1.bin`, `noise-1.2.1.bin` |
| `v1.4.0-rc.1` | `v1.3.0` | prerelease | `app-1.4.0-rc.1.apk`, `desktop-1.4.0-rc.1.zip`, `tool-1.4.0-rc.1.bin`, `noise-1.4.0-rc.1.bin` |

What each one is for:

- `app-*.apk` is a zip laid out like an Android package (stored dex, native library and asset
  entries), for the `apk` patcher that `auto` picks for `.apk`.
- `desktop-*.zip` is a plain zip with stored entries, for the `zip` patcher.
- `tool-*.bin` is raw bytes for the `binary` patcher. `v1.1.0` leaves it out, so a release without a
  matching asset is skipped without using up one of the `previous` slots.
- `noise-*.bin` is unrelated bytes in every release, so its patches come out near full size and
  `max-ratio` drops them.
- `v1.2.1` is a hotfix published after `v1.3.0`. In version order it comes before `v1.3.0`, so it is
  a source for `v1.3.0`, and `v1.3.0` is never a source for it.
- `v1.4.0-rc.1` is a prerelease, which is a source only with `prereleases: true`.

## Regenerating

```console
$ python3 make-fixtures.py dist
$ ./publish.sh dist
```

`publish.sh` creates the releases and is meant to run once, against an empty repository.
